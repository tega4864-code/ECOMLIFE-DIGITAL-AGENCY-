Free for commercial use, no attribution required. They are used as atmosphere only, never as "our clients" or "our team".
The .jpg files in this folder are only a fallback, used if Unsplash can't be reached (for example in the preview).

To change a photo, edit the photo ID in the src="https://images.unsplash.com/photo-..." address in the HTML.
To use your own photo instead, replace that src with images/your-file.jpg.
